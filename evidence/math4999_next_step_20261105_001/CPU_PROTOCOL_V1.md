# 首次越阈集合：本机CPU精确验证协议 v1

日期：2026-11-05。当前状态：READY_FOR_USER_REVIEW，尚未执行新科学实验。只准备本机标准库验证；不使用AutoDL、远程模型生成或原始数组。旧证明、旧CPU结果及16组真实实验保持原样。

## 目标和决定

本包检验“代码能否正确求出指定轨迹类的完整C_H”，同时检验哪些设定能唯一识别事件时间。C_H的精确计算与C_H是否为单点分开评价。单点H+1只表示窗口删失。

Opus5.5建议CPU先行，使用独立有理路径可行性判定、有限字母枚举、矩形见证与旧g比较。根采纳该方向，并作以下补全/纠正：
- 不采纳“再跑GPU只会重复阴性”的必然预测；当前仅缺乏值得追加GPU的依据。
- 自由方向类的理论递推本身是精确的；有限字母对它只能检验子集包含，不能据此独立验证整个连续类。检验完整时间集合的成员关系，不只检验凸包区间。
- 矩形最小值增加独立凸KKT证书与达界向量；只比较几个见证或G>=g不足以验证最小值精确。
- 严格绝对值越阈拆成正/负两个线性可行性分支。
- 固定离散theta按固定值分支、跨步保持；不能把它无声明地放松为连续区间。

## 固定参数和配置数

除纸笔专用反例外，CPU阈值为精确Fraction(1,5)，初态0。它不同于旧真实研究的binary64(0.20)，不更改后者的tau或H=80。所有数值以分子/分母字符串保存，不用浮点阈值或近似sqrt裁决。

A：48个一维连续区间配置。
lambda∈{-1,1/2,1,3/2}；各步独立D取[0,1/10]、[-1/10,1/10]或[1/10,1/10]；H∈{1,2,3,4}。4×3×4=48。
实现：前向存活闭区间递推。
独立oracle：把e_s直接展开成d_0…d_(s-1)的有理仿射式，对每个候选事件t施加此前|e_s|<=tau，再分别加e_t>tau、-e_t>tau。用通用Fraction Fourier–Motzkin消元（严格标记随正倍数求和用OR传播）判断可行；删失分支施加全部|e_s|<=tau。oracle不得调用存活区间或G函数。要求完整集合完全相等，不只包含。
FM约束按正比例规范化去重；0<=b或0<b直接精确判定。资源超限是技术失败，不能当不可行。

B：9个二维有限字母配置。
A取I、有理旋转[[3/5,-4/5],[4/5,3/5]]、非正规[[4/5,1],[0,4/5]]；各步D={ (0,-1/10),(0,1/10) }；H∈{1,2,3}，共3×1×3=9。
实现：只传播尚未越阈的精确有理向量集合。
独立oracle：枚举全部完整扰动序列，每条从e0重新递推并用欧氏范数平方>tau²求首次时间。不能调用存活集合实现。要求集合完全相等，保存每个时间的一条真实路径见证。配置最多8条路径；重复终点不等于重复来源数据。

G：18个有限矩形配置。
k∈{0,3/5,1}；六个矩形为：
1. [0,1/10]×[0,1/5]
2. [1/10,1/5]×[0,1/5]
3. [0,1/10]×[1/10,3/10]
4. [1/10,1/5]×[1/10,3/10]
5. [3/10,3/10]×[0,0]
6. [0,0]×[0,0]
实现四边截断候选，返回精确最小平方及其(x,y)。
独立证书：对返回点检查可行性、q=G²和box KKT符号（固定坐标不限制导数；自由内点导数0；下边导数非负、上边非正）；结合0<=k<=1的半正定Hessian证明全局最优。取beta=(x,0)、p=(-k y,sqrt(1-k²)y)，这里sqrt依k精确为1、4/5、0，因此向量全部有理，另核对范数/内积/和的平方，确保达界。与旧g的精确平方比较，新G²>=g²。不得用普通浮点sqrt作oracle。

R：6个自由方向k=1配置。
固定H=4、a=d，设(m,L,a)和纸笔期望集合：
(0,0,1/10) -> {5}
(0,0,3/10) -> {1}
(1/2,1/2,1/10) -> {5}
(1,1,1/10) -> {3,4,5}
(2,2,1/10) -> {2,3,4,5}
(4,4,1/10) -> {2}
实现以存活半径区间计算G1的区间距离，全部Fraction。返回完整可实现时间集合及每步半径区间；不把一般嵌套根式实现塞入本包。
纸笔依据：m0为恒定缺陷；m1/2时上界(1/5)(1-2^-t)<tau；m1到第2步仍安全且从第3步可越阈/可继续安全；m2从第2步可越阈且存活半径[1/10,1/5]可维持；m4第1步1/10安全、第2步最小3/10，故唯一时间2。连续方向的可实现性来自已证定理，不伪称有限枚举穷尽。
交叉检查：A的每个连续一维类嵌入二维自由方向类，取m=L=|lambda|、缺陷范数范围为相应D的真实绝对值范围，k1。要求A的精确C是对应自由方向C的子集；允许严格包含。

P：6个单列纸笔对照记录。
P1 A=1,D=[9/100,1/10],tau1/5,H3 -> {3}。
P2 A=0,D={1/5},tau1/5,H3 -> {4}（等号安全）。
P3 A0=0,D0={0,1}; A1=-1,D1={1};tau1/2,H2 -> {1,2}，其中D0为有限字母而非[0,1]。
P4 A均0,D0=[0,1],D1={0},D2={1};tau1/2,H3 -> {1,3}（孔洞）。
P5 theta∈{-1,1}跨步固定，e1=theta,e2=e1-theta,tau3/2,H2 -> {3}；故意逐步重选的负对照 -> {2,3}，必须被识别为更大/错误的模型类，而非合法实现通过。
P6 A=1,各步D={-1/10,1/10},tau1/5,H4 -> {3,5}；与自由方向m=L1的{3,4,5}比较，展示不同信息类不能要求相等。

合计87个预定记录（48+9+18+6+6）。A的48项包含交叉检查不是额外独立样本。正例、阴性、删失和无增益全部保存；无数据总体推断、p值或置信区间。

## 验收、资源和停止条件

正确性：
1. A/B的实现C与对应独立oracle逐配置完全相等。
2. G每项KKT、达界向量、G>=g全部通过。
3. R/P的全部纸笔期望匹配，A跨类包含通过。
4. 固定theta负对照必须暴露伪时间2；不能把预定故障检出计作合法实现失败。
5. 非法参数、空矩形、不合法H、输入长度不符及严格等号有必要单元测试。

报告完整集合、事件/删失、集合基数/孔洞、凸包宽度、安全前缀/有限右端点、错误唯一识别、拒答和技术失败；数值设定不当作数据样本。不同信息类的增益单列，不归因于同信息算法优越。

运行总上限600秒，FM每个消元阶段最多10000条去重约束，超限立即记技术失败并保留已有输出，不改网格、不换oracle或重试。任何合法配置错配、证书失败或负对照未检出，停止发布‘全通过’结论，先独立定位。没有新模型调用、服务器启动、下载或付费云算力。
