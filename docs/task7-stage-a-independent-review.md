## 数学解释与限制

实际步长中心割线为 q = (F₊ − F₋)/(h₊ + h₋)。在理想连续映射沿方向的三阶导数有界、评估误差有界且正负步长对称等附加假设下，才可得到 O(h²) + O(u/h) 形式的误差估计；步长不对称还会引入额外项。实验通过不是这些假设已经成立的证明。

本轮只测试一个状态、一个噪声种子和 v0 方向；跨方向可加性未检验。FP32 使用同一组已加载权重的转换值，不恢复量化前信息。原生与 FP32 路径差异支持计算精度路径影响本次测量，但不意味着模型不存在非线性。
