## A：现有数据上的一次本地 CPU 诊断（下一步优先）

**目标和假设。** 在固定评分及数据下，检查经认证的像素盒 CAL 界是否改善已有径向法，并能否在保留已知真标签的同时收窄个体有限时间范围。无改善是有效结果，不证明其他参数或像素约束最优方法无效。阈值降低本身不是成功。

**冻结的数据和信息边界。** 使用旧 DEV 5来源的存储参考、尺度及预处理；CAL 5来源共享的5个80帧真实 RGB 视频和对应两种子共10条既有误差轨迹；TEST 6来源各两条的目标标签。仅 TEST01 seed 0 有本地生成48帧可直接作像素候选评分，其余11条单独报告通用兜底。H=80，严格 \(E>0.20\)，等号安全，删失是独立第81个标签而非第81帧。固定全部身份、输入哈希、帧次序、中心/尺度、预处理、离线 oracle 未来姿态控制、已有真标签及前缀。全体候选为1--80和删失；公共基线 \(\mathcal C_0=6..71+\dagger\)，67标签。不得把测试真 RGB 输入预测集合。

**前提门槛。** 2026-11-10 只读核查在 `evidence/math4999_box_design_20261110_001/PROVENANCE_READONLY.json` 记录：历史生产/提取代码哈希与 campaign、receipt 对应，CAL JSON 哈希与 receipt 和旧 INPUTAUDIT 对应，5×2×80分组顺序一致；历史流程对用于计算误差的同一 float 数组执行裁剪和范围检查，支持生成像素落在[0,1]的前提。这不是对缺失 CAL 数组的直接查看，也不是外部签名认证。运行时须重新核对 campaign、task8、task11、保存的提取代码和 receipt 的完整链，确认范围检查发生在同一生成数组和同一误差计算之前；仅有三个缓存不足以替代此链。如链断裂、来源/帧次序、阈值、尺度或数值包围不一致，立即停止新盒约束科学计算。不得裁剪缺失生成数组后沿用旧 E。

**三臂与冻结参数。** 径向原法、安全项盒上界、双侧盒上界；双侧为预先指定主臂。固定同一候选评分及保守前缀规则，参数及向外数值认证严格依理论文档：逐帧两符号共享 \(\Lambda=\{0,\text{stored}(R_{mid}/(2E_{mid}))\}\)，第二项无效时只用零，不搜索参数；各方法保守界与旧界比较保持嵌套。分别求 CAL 的 floor 区间及阈值上界，对所有81标签算集合，而非只算公共集合。已知48帧之后所有有限标签及删失用原前缀下界政策，不能称为完整尾部可行性。

**结果与判定。** 汇报每 CAL 运行的 floor/upper 括区、最大后的 q_floor 与 Q 上界及相对径向法变化；对每臂报告完整标签成员、有限标签集合 \(F=\Gamma\cap\{1,\ldots,80\}\)、有限候选数、删失、总数、删除的公共标签、添加到公共集合外的标签、真实 T=30 是否保留。若 F 非空，报告端点 \(\min F,\max F\) 和整数跨度 \(\max F-\min F+1\)；空 F 的端点和跨度均记 null，绝不把删失当作数值端点81。全81标签兜底的有限凸包是1--80；空集合永远不覆盖。

预指定主目标：真标签被保留，且整个 \(\Gamma\subseteq\mathcal C_0\)，并且 F 为空（此时只有删失标签且真标签必须删失），或 F 非空且整数跨度小于66。这证明端点范围相对公共有限范围6--71确实收窄，而不只是删除内部标签。只有删失的正确结果单独报告为排除有限时点，不称为时间区间。此处已知 T=30，所以覆盖时 F 必须非空。次要目标为真标签保留且总标签数<67的集合缩减；另分别报告 \(\Gamma\) 是否为 \(\mathcal C_0\) 严格子集、任一公共标签是否被删除，以及保留真标签时是否为径向法严格子集。来源级双种子成功计数 k/6 只作描述，11条兜底使6/6不能作为新泛化证据。对全部67个公共标签，比较候选 \(C_{upper}\le q_{floor,box}^{lower}\)，报告全/部分/无不可删除；未通过是未知，不代表可删除。不得将 floor 充当新的 Q。

**先决验证计划，不在本次执行。** 正式计算前先做纯证明与固定常数边界检查：R=0、E=0、阈值等号、安全/越界、全删失、未知尾部、饱和像素、w=0、单坐标精确有理支持值、±对称、畸形输入；小已知向量检验对偶上界不小于可行目标、界单调、三臂嵌套及 floor≤native≤upper。无效包围、标签不符或数值不一致中止，不能静默修正。上述检查为拟议执行的一部分，目前没有运行。

**资源与输出。** 一次受监督本地 CPU 执行，固定边界测试、预检、科学计算与写出合计硬上限600秒；峰值工作集和 private commit 各不超过1.5 GiB。时间估计为数分钟、未实测，不保证600秒内完成；旧过程峰值已接近1.23 GiB，逐帧流式读取，不能同时保留全部 RGB 加新临时数组，避免三维参数数组。只用现有本地依赖，一次尝试，不自动重试或参数搜索；CAL 最多约800帧及48帧已知 TEST。无GPU租用费、AutoDL、下载或新增服务费用。新派生输出不超过100 MiB；如需约128 MiB冻结中心缓存，临时存储另限512 MiB，获运行授权后正常清理。超时、超内存或中断的部分输出不是完成的阴性结果。

拟输出 `RESULTS.json`、81行候选 CSV、各 CAL 运行上下界、输入溯源、资源与失败记录、一页中文结论及独立审查。无新模型预测，也不对未直接检查的11条运行补算。

## B：未来8来源扩展的设计修订，未准备生成

8个新增本地输入仍全部留作 TEST，目前零新预测；旧16来源结果单独标记为回顾性。保留原径向臂及公共基线，任何盒算法必须在新结果出现前固定，使用旧 CAL，禁止留一法、用新 TEST 标签再校准或预测时访问未来真帧。每来源同一 checkpoint、两原种子、完整80帧模型输出；主分析仅用48帧生成前缀，次分析用全部80帧，目标均为80帧内首次越界。保存完整 float 数组，在揭示 TEST 真误差前封存预测集合。
